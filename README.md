# Зертханадан қашу — 3D виртуалды зертхана (Электр тізбегі)

Физика сабағына арналған браузерлік 3D квест-зертхана. Оқушы қараңғы физика
кабинетінде қалып қояды: есік электронды құлыппен жабылған, ал құлыптың коды —
компьютердегі тапсырманың жауабы. Жауапты табу үшін жұмыс үстелінде шамдарды,
аккумуляторды, амперметр мен вольтметрді сыммен жалғап, нақты тізбек құрастыру керек.

**Сынып:** 8-сынып (Ом заңы, тізбектей және параллель жалғау)
**Тіл:** қазақша
**Талап:** заманауи браузер (Chrome, Edge, Firefox, Yandex). Орнату қажет емес.

---

## Ойнау

Сілтемені ашу жеткілікті — компьютерде, планшетте, телефонда немесе
интерактивті панельде жұмыс істейді.

| Құрылғы | Басқару |
|---|---|
| Компьютер | `W A S D` — жүру, тінтуір — қарау, `E` — әрекет, `Shift` — жүгіру |
| Сенсорлық экран | экрандағы джойстик, сүйреп қарау, `E` батырмасы немесе затқа түрту |
| Телефон-джойстик | QR кодты сканерлеп, телефонды пультке айналдыру (төменде) |

Жоғарғы оң жақтағы батырмалар: `📱` — телефонмен басқару (QR), `🎮` — экрандық
джойстик, `⛶` — толық экран.

---

## Телефон-джойстик (QR)

Панельде/проекторда ойын ашылады, ал оқушы өз телефонынан басқарады: жүреді,
қарайды, тізбекті телефонда құрастырады, кодты телефоннан енгізеді.
Панельдегі ойында **📱** батырмасын басып, QR кодты телефонмен сканерлеу керек.

Қосылудың екі жолы бар, ойын оны **автоматты түрде** таңдайды:

**1. Интернет арқылы (WebRTC).** Ойын осы сілтемеден ашылса, сервер керек емес.
Телефон мен панель бір Wi-Fi-да болуы міндетті емес — екеуінде интернет болса жеткілікті.

**2. Жергілікті сервер арқылы (интернетсіз).** Кабинетте интернет болмаса немесе
байланыс тұрақсыз болса — төмендегі «Интернетсіз» бөлімін қараңыз. Бұл нұсқа ең
жылдам әрі ең сенімді.

---

## Интернетсіз (кабинетте, өз Wi-Fi-ыңызбен)

1. Репозиторийді жүктеп алыңыз: **Code → Download ZIP** → мұғалімнің ноутбугына
   тарқатыңыз. Ноутбукте Python орнатылған болуы керек
   ([python.org/downloads](https://www.python.org/downloads/), орнатқанда
   «Add Python to PATH» белгісін қойыңыз).
2. Ноутбук пен телефондар **бір Wi-Fi желісіне** қосылады. (Мектеп Wi-Fi-ы
   құрылғыларды бір-бірінен оқшауласа — телефоннан hotspot таратып, ноутбукты
   соған қосыңыз, немесе кабинетке жеке роутер қойыңыз.)
3. **`start.bat`** файлын екі рет басыңыз. Терезе ашылып, сілтеме көрсетеді:
   `http://192.168.x.x:8080/`. Windows брандмауэрі сұраса — «Жеке желілер» үшін
   рұқсат беріңіз.
4. Панельде **дәл сол сілтемені** ашыңыз (`localhost` емес, IP-мекенжайы барын!).
5. **📱** → QR → телефонмен сканерлеу. Дайын.

Серверді тоқтату үшін қара терезені жабыңыз.

## Ойынның барысы

1. **Жарық.** Бөлме қараңғы — есіктің қасындағы қабырғадан ажыратқышты тауып жағу.
2. **Компьютер.** Мониторға жақындап, тапсырманы оқу (батарея кернеуі, екі шамның
   кедергісі, не өлшеу керектігі). Тапсырма әр ойында кездейсоқ таңдалады.
3. **Жұмыс үстелі.** Аккумулятор, екі шам, амперметр, вольтметрді сыммен жалғау:
   клемманы басып, екінші клеммаға сүйреу. Сымды алып тастау — оны басу.
4. **Өлшеу.** Аспаптардың көрсеткішін оқу. Тізбек нақты физикамен есептеледі
   (түйіндік талдау): шамдар қуатына қарай жанады, қате жалғағанда қысқа
   тұйықталу туралы ескерту шығады.
5. **Код.** Табылған санды компьютерге енгізу. Қате болса — қайта тексеру, қажет
   болса кеңес алу.
6. **Шығу.** Есік ашылады, дәліз арқылы шығу. Соңында уақыт, әрекет саны, баға
   (★) және есептің толық шешімі көрсетіледі.

### Тапсырма түрлері

Әр ойында осы төртеуінің бірі кездейсоқ беріледі (сандар да әр жолы басқа,
жауаптары әрқашан бүтін немесе «әдемі» сан болатындай іріктелген):

- тізбектей жалғаудағы ток күші (мА);
- тізбектей жалғауда 2-шамдағы кернеу (В);
- параллель жалғаудағы жалпы ток (мА);
- параллель жалғауда 1-шамның тогы (мА).

## Сабақта қолдану туралы

- **Сынып режимі:** панель + телефон-джойстик. Бір оқушы басқарады, сынып бірге
  талқылайды. Түсіндіргеннен кейін бекіту үшін ыңғайлы.
- **Жеке режим:** әр оқушы өз құрылғысында сілтемені ашып, өзі орындайды.
- Алдымен **қалыптастырушы бағалауда** қолданған жөн: техникалық ақау (Wi-Fi,
  телефон) БЖБ кезінде дау тудыруы мүмкін.
- Бағаны уақытқа емес, физикалық әрекеттерге қарап қойған дұрыс: тізбекті дұрыс
  құрастырды ма, амперметрді тізбектей / вольтметрді параллель қосты ма,
  қысқа тұйықталуға жол берді ме, неше әрекеттен тапты.

## Файлдар

| Файл | Қызметі |
|---|---|
| `index.html` | ойынның бүкіл коды (3D сахна, тізбек шешуші, телефон-джойстик беті) |
| `three.min.js` | 3D кітапханасы (three.js r128) |
| `qrcode.min.js` | QR код генераторы |
| `peerjs.min.js` | телефонмен интернет арқылы байланысу (WebRTC) |
| `server.py` | интернетсіз жұмыс істейтін шағын сервер (тек Python стандартты кітапханасы) |
| `start.bat` | серверді Windows-та іске қосу |

Кітапханалар папкада бірге тұр — ойын интернетсіз де толық жұмыс істейді.
Файлдарды бөліп тастамаңыз.

## Техникалық сипаттама

- **3D:** three.js, бірінші жақтан көрініс, процедуралық текстуралар (еден, қабырға,
  тақтадағы формулалар, терезе, плакаттар) — сыртқы сурет файлдары жоқ.
- **Тізбек:** модификацияланған түйіндік талдау (MNA) — Гаусс әдісімен нақты
  шешіледі. Амперметрдің кедергісі нөлге тең, вольтметрдікі 10 МОм, батареяның
  ішкі кедергісі 0,001 Ом. Сондықтан аспаптардың көрсеткіші оқулықтағы мәндермен
  сәйкес келеді.
- **Желі:** `#c=КОД` белгісі бар сілтеме телефонды «пульт» режимінде ашады.
  Байланыс арнасы автоматты таңдалады: жергілікті сервер (long-poll) → PeerJS (WebRTC).
- Бүкіл код бір файлда, сыртқы тәуелділік жоқ.
